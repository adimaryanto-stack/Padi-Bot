FAQ & DOKUMENTASI

Pertanyaan yang Sering Diajukan

Apakah PadiBot bisa bekerja tanpa sinyal internet di sawah?

Ya, 100% bisa. Aplikasi Android PadiBot didesain offline-first dengan database SQLite lokal. Komunikasi langsung ke robot menggunakan WiFi lokal (Access Point dari ESP32) atau Bluetooth BLE tanpa memerlukan paket data seluler atau router eksternal.

Berapa akurasi modul GPS yang digunakan?

Untuk modul standar u-blox NEO-6M/8M akurasi berkisar 1.5 - 2.5 meter. Untuk penanaman otonom presisi tinggi berjarak legowo rapi, sistem mendukung modul RTK GNSS (u-blox ZED-F9P) dengan akurasi sentimeter (±2.5 cm).

Bagaimana cara memasang firmware Arduino ke robot?

Firmware disediakan secara open-source di repository GitHub kami. Anda cukup membuka file proyek menggunakan PlatformIO atau Arduino IDE, lalu meng-upload kode `.ino` ke Arduino Mega via kabel USB.
